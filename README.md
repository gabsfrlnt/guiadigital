O Guia Digital é um projeto desenvolvido como parte da Atividade Extensionista II – Tecnologia Aplicada à Inclusão Digital, do curso de Gestão da Tecnologia da Informação.

O projeto tem como objetivo facilitar o acesso da comunidade a serviços digitais e informações importantes, reunindo em um único site links para serviços públicos, saúde, educação, trabalho, cidadania, trânsito e outras áreas.
-----------------------
Desenvolvido para fins acadêmicos e sociais.
